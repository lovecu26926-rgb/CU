# CU Automation

CU 업무 자동화 및 외부 트렌드 감시 프로젝트입니다.

## 예정 구성
- CU 바이럴 상품 감시: Google Trends, YouTube, 공개 커뮤니티/SNS 신호 확인
- Telegram 알림: 급상승/폭발 징후가 있을 때만 전송
- GitHub Actions: 클라우드에서 정기 실행
- 점포 분석: 매출·폐기·발주 데이터를 별도 로직으로 분석

## 원칙
- 복잡한 점수화보다 갑작스러운 검색량/노출 증가 여부를 우선 판단
- 공식 홍보보다 실제 사용자 반응, 품절·재고 문의, 구매 인증을 중요하게 봄
- 로컬 PC가 꺼져 있어도 외부 바이럴 감시는 계속 동작하는 구조를 목표로 함
